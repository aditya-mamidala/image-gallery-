# ImageGallery

Premium, responsive frontend project created for the CodeAlpha Frontend Development internship tasks.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Deploy with GitHub Pages
1. Create a repository named `CodeAlpha_ImageGallery`.
2. Upload the files in this folder to the repository root (`index.html`, `style.css`, `script.js`, and this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Notes
- Uses plain HTML, CSS and JavaScript.
- Google Fonts and (for the gallery) Unsplash images require an internet connection.
- Personalize any placeholder links, contact details and content before submitting.
